# Her Next Life 🌸

### Wellness • Friendship • A Brighter Tomorrow

**Her Next Life** is a community created especially for mothers and women aged 40+ to connect, make new friends, explore hobbies, and focus on their health and happiness.

Our goal is to create a supportive and welcoming space where women can stay active, socially connected, and enjoy every stage of life.

## 🌷 About the Project

Her Next Life brings women together through wellness activities, creative experiences, meaningful conversations, and virtual meetups.

We believe every woman deserves time for herself, opportunities to grow, and a community where she feels valued and supported.

## ✨ Website Features

- **Home:** Introduction to Her Next Life and its vision.
- **About Us:** Our mission, vision, and community values.
- **Activities:** Explore wellness, yoga, meditation, creative workshops, and virtual meetups.
- **Join Our Community:** Registration for interested women.
- **Contact Us:** Connect with the Her Next Life team.

## 🚀 Run Locally

1. Clone this repository:

   ```bash
   git clone https://github.com/shivani-vishwakarmaa/her-next-life.git
   ```

2. Open the project folder:

   ```bash
   cd her-next-life
   ```

3. Open `index.html` in your browser.

No additional dependencies or build tools are required for the plain HTML, CSS, and JavaScript version.

## 🌐 Deployment

This project can be hosted for free using GitHub Pages, Cloudflare Pages, or Netlify.

For GitHub Pages:

1. Open repository Settings.
2. Select Pages.
3. Choose Deploy from a branch.
4. Select `main` and `/ (root)`.
5. Save and wait for deployment.
